# 🎨 MakeAWish — Frontend Web Client

This directory contains the client-side single page application (SPA) for **MakeAWish**, built with React 19, Vite, TypeScript, Tailwind CSS, Framer Motion, and Three.js.

For comprehensive project documentation, architecture overviews, screenshots, and full-stack setup instructions, refer to the [Root README](../README.md).

---

## 🚀 Quick Start (Frontend Only)

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Ensure `VITE_API_URL`, `VITE_SUPABASE_URL`, and `VITE_SUPABASE_ANON_KEY` are configured.

### 3. Start Development Server
```bash
npm run dev
```
The app will run locally at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```

### 5. Preview Production Build
```bash
npm run preview
```
